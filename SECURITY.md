# Security Policy

## Supported Versions

Sentinel Scan is an educational and research-focused cybersecurity project. The latest version available in the main branch is currently supported for security-related fixes and improvements.

## Reporting a Vulnerability

If you discover a security issue or vulnerability related to Sentinel Scan, please report it responsibly.

You can report issues through:

* GitHub Issues
* GitHub Security Advisories
* Direct contact via GitHub profile

Please include:

* Description of the issue
* Steps to reproduce
* Expected impact
* Screenshots or logs if available

## Responsible Usage

Sentinel Scan is designed only for passive and authorized website security assessments.

Users must:

* Only scan systems they own or are authorized to assess
* Avoid intrusive or illegal testing
* Follow ethical cybersecurity practices

The project does not support:

* Exploitation
* Brute-force attacks
* Denial-of-service testing
* Unauthorized access attempts

## Disclaimer

This tool is provided for educational and defensive security purposes only. The developer is not responsible for misuse or unauthorized activities performed using this software.
